# MarioAI Character Universe — GitHub Pages / No npm

Upload `index.html` directly to a GitHub repository and enable GitHub Pages.

Features: character creator, local persistent saves, memory, emotions, HP/death, cinematic mode, 10,000-character chat limit, and optional OpenAI-compatible chat/image API settings.

**Security:** API keys entered in this static site are stored in the browser and are not protected from the browser/network. Do not use a valuable production secret this way. For production, use a secure backend/serverless proxy.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.
